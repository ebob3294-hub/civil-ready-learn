# Civil Defense Hub

Create a mobile-first web application using React and Tailwind CSS for Civil Defense (Protection Civile / Pompiers) training, structured for easy integration into Android Studio using Capacitor.

Key Features Required:

1. **Theme & Styling**: Professional emergency-services design (crimson red, dark gray, and clean white accents) with a smooth, native mobile app feel.

2. **Dashboard**: Quick-access cards for Lessons and QCM Tests.

3. **Lessons Section**:

   - Organized by levels (e.g., Niveau 1, Niveau 2, Niveau Avancé) and categories (Incendie, Secourisme, Opérations Diverses, Matériel).

   - Clean, readable layout for text content, headings, and key safety rules.

4. **QCM (Quiz) Section**:

   - Interactive multiple-choice questions for knowledge testing and reconnaissance levels.

   - Real-time score tracking, instant right/wrong feedback, and a final results summary screen with a restart option.

5. **Mobile Optimization**: Fully responsive UI designed to fit perfectly inside mobile viewports, ready for web-to-native wrapping.
